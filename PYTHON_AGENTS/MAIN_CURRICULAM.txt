

# 🚀 Generative AI + Agentic AI Curriculum (From Zero to Advanced)

This roadmap is designed for **Python learners** (you already have Python experience 👍), and focuses on **hands-on projects**, not just theory.

---

## 🧩 PHASE 0: Prerequisites (Quick Foundation)

*(Fast recap – no heavy theory)*

### Topics

* Python essentials for AI
* Virtual environments
* APIs & JSON basics
* Basic Git & project structure

### Mini Project

✅ **API Data Fetcher**

* Fetch data from a public API
* Clean and display output in terminal

---

## 🧠 PHASE 1: AI Fundamentals (Zero Level)

### Topics

* What is AI, ML, Deep Learning (simple difference)
* What is **Generative AI**
* Rule-based AI vs Generative AI
* Tokens, prompts, models (easy analogy)

### Mini Project

✅ **Rule-Based Chatbot**

* If/else based chatbot
* Understand why it’s *not* GenAI

---

## 🤖 PHASE 2: Generative AI Basics

### Topics

* What are LLMs (GPT, Gemini, Claude)
* How text generation works (very simple)
* Prompt Engineering basics
* System, user, assistant roles

### Live Project 1

🔥 **AI Chatbot (Console)**

* Use OpenAI / Gemini API
* Ask questions, get answers
* Prompt tuning for better replies

## 🧪 PHASE 3: Prompt Engineering (Practical)

### Topics

🔥 **AI Resume Generator**

* Input: name, skills
